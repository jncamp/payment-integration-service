Stripe Payment Integration API

A production-style Java/Spring Boot backend demonstrating Stripe Payment Intents, refunds, webhook handling, API key security, PostgreSQL persistence, Docker, and Railway deployment.

Try the payment workflow

This public demo form creates a Stripe test Payment Intent and confirms it with Stripe's test payment method pm_card_visa. No real card or real charge is used.

Ready.

Click "Create payment intent" to begin.

The real REST API remains protected by X-API-Key. This form uses separate public demo endpoints under /demo/api so clients can test the deployed project without Postman.

What this service demonstrates

  • Create and confirm Stripe payment intents
  • Partial and full refund workflows
  • Idempotent request handling
  • Webhook event processing
  • Validation and structured error handling

Security

Payment and refund endpoints are protected. API requests require this header:

X-API-Key: your_api_key_here

Example request

POST /api/payment_intents
Content-Type: application/json
X-API-Key: your_api_key_here

{
  "amount": 1000,
  "currency": "usd",
  "customerName": "Demo Customer",
  "customerEmail": "demo@example.com"
}
